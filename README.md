# Advokatska kancelarija Kostić — sajt

Statički sajt za advokat Milenu Kostić, Niš. Jedan fajl (`index.html`), bez build koraka.

## Objavljivanje na GitHub Pages
1. Napravite novi repozitorijum i ubacite sadržaj ovog foldera.
2. Settings → Pages → Source: `Deploy from a branch`, grana `main`, folder `/ (root)`.
3. Sajt je dostupan na `https://<korisnik>.github.io/<repo>/`.

Za sopstveni domen (npr. advokatkostic.rs) dodajte fajl `CNAME` sa nazivom domena.

## Pre objavljivanja zameniti
- Adresu, telefon i e-poštu (Kontakt + podnožje)
- Iskustva klijenata (trenutno primeri)
- Portret i mapu (trenutno prazna polja)
- Kontakt i zakazivanje rade samo u pregledu — za stvarno slanje povežite formu (npr. Formspree)

`assets/` sadrži logo u 4 varijante i monogram (tamni i svetli).
